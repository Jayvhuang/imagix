Frequently asked questions

常见问题

Will resizing reduce image quality?

Enlarging beyond the original size can soften detail; shrinking generally preserves quality. Imagix re-draws the image at the target size using the browser's image engine.

What does aspect-ratio lock do?

It keeps width and height proportional so the image is not stretched or squashed.

Which formats can I export?

PNG (lossless, supports transparency), JPEG (smaller, no transparency) and WebP.

缩放会降低画质吗？

放大超过原始尺寸会让细节变软；缩小通常会保留画质。Imagix 使用浏览器的图像引擎将图片重绘到目标尺寸。

锁定宽高比有什么用？

它让宽高保持等比，图片不会被拉伸或压扁。

可以导出哪些格式？

可导出 PNG（无损、支持透明）、JPEG（更小、无透明）和 WebP。
