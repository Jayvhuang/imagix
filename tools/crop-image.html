Frequently asked questions

常见问题

Can I crop to exact pixels?

Yes — the readout shows the selected region in source pixels (x, y, width, height).

Does cropping reduce quality?

Cropping only removes pixels; the kept area keeps its original resolution.

Is cropping done on my device?

Yes, entirely in your browser via the Canvas API.

可以裁剪到精确像素吗？

可以——读数会以原图像素显示选区（x、y、宽、高）。

裁剪会降低画质吗？

裁剪只移除像素；保留区域保持原始分辨率。

裁剪是在本机完成的吗？

是的，完全通过浏览器 Canvas API 在本地完成。
