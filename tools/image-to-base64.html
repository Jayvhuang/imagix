Frequently asked questions

常见问题

What is a Data URL?

It encodes an image as base64 text so it can be embedded directly in code instead of a separate file.

Why is my Data URL large?

It grows with image size; base64 is about 33% larger than the binary file.

Is this safe for private images?

Processing is local, but a Data URL pasted elsewhere is plain text anyone can read.

什么是 Data URL？

它将图片编码为 base64 文本，从而可直接嵌入代码，而无需单独文件。

为什么我的 Data URL 很大？

它会随图片大小增长；base64 约比二进制文件大 33%。

私密图片用这个安全吗？

处理在本地进行，但粘贴到别处的 Data URL 是任何人都能读取的纯文本。
